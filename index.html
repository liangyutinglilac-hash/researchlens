03 / GET STARTED

把科研工作台运行起来

网页预览

解压后打开 index.html，即可使用此入口页。无需构建工具或安装前端依赖。

完整应用

安装 Python 3.12，在 backend 目录创建环境并安装依赖，随后启动 Streamlit。配置自己的模型接口后，即可使用 AI 解读与科普脚本功能。

阅读完整启动说明 ↗
cd backend
python3.12 -m venv .venv-py312
source .venv-py312/bin/activate
pip install -r requirements.txt
sh start.sh

视频依赖 FFmpeg 与可用语音服务。OpenAlex、PubMed 和模型接口受各自网络、额度及服务能力限制。
